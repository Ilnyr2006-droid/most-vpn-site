# Подключение оплаты

Сайт заранее содержит страницы `/checkout`, `/checkout/success`, `/checkout/cancel`, серверный endpoint `/api/checkout` и fail-closed webhook `/api/payment/webhook`.

Перед включением платежей:

1. Выбрать провайдера и подтвердить реальные цены в `lib/plans.ts`.
2. Реализовать SDK/API провайдера в `lib/payment.ts`. Сумму брать только из серверного каталога тарифов.
3. Передавать провайдеру уникальный ключ идемпотентности, email для чека и return URL.
4. В `/api/payment/webhook` проверить подпись и статус повторным запросом к провайдеру.
5. Выдавать VPN-доступ только после подтверждённого webhook. Повтор webhook не должен создавать второй доступ.
6. Сохранять связь: внутренний order id, provider payment id, plan id, сумма, валюта, статус и время.
7. Настроить `/checkout/success` и `/checkout/cancel` как return URL. Страница success сама по себе не подтверждает оплату.
8. Заполнить переменные из `.env.example`, проверить тестовую среду провайдера и затем провести один реальный платёж минимального тарифа.
